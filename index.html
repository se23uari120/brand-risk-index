TOPSIS Methodology — Step-by-Step
1
Decision Matrix Construction
Build matrix X (m×n) where m = companies and n = 4 MCDM criteria. Each cell x𝐼ⱼ represents the performance of alternative i on criterion j, sourced from FinBERT sentiment scores, media monitoring APIs, and regulatory databases.
2
Normalised Decision Matrix
Each value is normalised: r𝐼ⱼ = x𝐼ⱼ / √(Σ x²𝐼ⱼ). This eliminates dimensional differences between criteria, ensuring fair comparison across severity, reach, recoverability, and criticality.
3
Weighted Normalised Matrix (AHP Integration)
Multiply each column by its AHP weight: v𝐼ⱼ = wⱼ · r𝐼ⱼ. Weights derived via AHP pairwise comparisons: [0.35, 0.28, 0.22, 0.15]. This embeds expert judgment into the quantitative model.
4
Ideal Best & Ideal Worst Solutions
A+ (ideal best) = {min values for cost criteria}; A− (ideal worst) = {max values for cost criteria}. All 4 criteria are cost-type (higher value = greater brand risk). The ideal best corresponds to lowest risk exposure.
5
Euclidean Distance Computation
D+𝐼 = √(Σ(v𝐼ⱼ − A+ⱼ)²) — distance from ideal best. D−𝐼 = √(Σ(v𝐼ⱼ − A−ⱼ)²) — distance from ideal worst. Both are computed across all n=4 weighted criteria for each company.
6
Closeness Coefficient & Final Risk Score
Risk Index CC𝐼 = D+𝐼 / (D+𝐼 + D−𝐼). Measures relative distance from safe baseline (A+) towards crisis state (A−). Final Risk Index = CC𝐼 × 100. Thresholds: Low [0–40], Moderate [41–70], Critical [71–100].
